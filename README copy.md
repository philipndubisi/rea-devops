
Infrastructure automation and DevOps tools for Rea Interactive Bible project

Overview

This repository contains all infrastructure code, deployment scripts, monitoring tools, and configuration files for the Rea waitlist application.

Quick Start
For New Team Members

1. Clone repository:
   git clone https://github.com/rea-interactive-bible-devops/rea-devops.git
   cd rea-devops


2. Read documentation:
   - Setup Guide](docs/SETUP.md)
   - Architecture Overview](docs/ARCHITECTURE.md)
   - Deployment Guide](docs/DEPLOYMENT.md)

3. Get server access:
   - Request SSH credentials from  team lead
   - Test connection: `ssh username@server_ip`

4. Pick a task:
   - Check [Issues](https://github.com/rea-team/rea-devops/issues)
   - Assign yourself to a task
   - Create feature branch

Contributing

1. Create feature branch: `git checkout -b feature/your-task`
2. Make your changes
3. Test thoroughly
4. Commit: `git commit -m "Description"`
5. Push: `git push origin feature/your-task`
6. Create Pull Request
7. Request review from 2 team members
8. Merge after approval
